# Data Modeling  

## Resources  

### Website  
The dataset used for analysis is sourced from the NYC Taxi and Limousine Commission (TLC).  
**Link:** [NYC TLC Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)  

### Data Dictionary  
For understanding the dataset's structure and attributes, refer to the official data dictionary:  
**Link:** [NYC TLC Data Dictionary (Yellow Taxi)](https://www.nyc.gov/assets/tlc/downloads/pdf/data_dictionary_trip_records_yellow.pdf)
